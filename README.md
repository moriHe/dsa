# Data Structures & Algorithms — Knowledge Document

## Overview

This repository contains programming assignments and solutions from the Princeton University / Coursera courses:

- Algorithms, Part I
- Algorithms, Part II

The content is organized into several course or module directories (`m_01` through `m_06`) and is intended as practical training in classical algorithms and data structures.

## Focus

Unlike the application-oriented projects, the primary focus here is not product development but algorithmic thinking.

This includes:

- Analyzing problems
- Selecting appropriate data structures
- Considering runtime behavior
- Considering memory usage
- Correctly implementing algorithms

## Demonstrated Skills

- Data structures and algorithms
- Algorithmic problem solving
- Awareness of computational complexity
- Systematic work on programming problems
- Practical study of fundamental computer science concepts
